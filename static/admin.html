E2E Tests
Black-box API tests against the default Dewey Decimal wiki page, using the server's default engines. Each phase deletes prior state, then exercises a live endpoint.
Target document
https://en.wikipedia.org/wiki/Dewey_Decimal_Classification
1 · Test Ingestion

Deletes the existing Dewey document, re-ingests the URL with default enrichment, and waits until it reaches ready with an embedding.

2 · Test Query

Runs a search with the server's default ranker and asserts the Dewey document is returned.
