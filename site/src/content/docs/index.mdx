<section class="band band--intro">
  <span class="band-lead">What is Dewie</span>
  <p class="band-desc">
    Dewie is a <strong>self-hosted knowledge base for your AI agents</strong>. Feed it web
    pages, PDFs, feeds, or files, and it reads and organizes each one automatically. Your
    agent can then search everything it has collected — and follow the links between
    documents — through a simple API or MCP. Runs locally, no API key required.
  </p>
</section>

<section class="band band--example">
  <span class="band-lead">Quickstart</span>
  <h2 class="band-title">Running locally, three commands</h2>
  <p class="band-desc">No API key, no config — a fresh install embeds its own model in-process.</p>

```bash
pip install "dewie[local]"
dewie setup
dewie serve      # REST API + MCP server on http://localhost:10946
```

  <p class="band-desc" style="margin-top:0.7rem; font-size:0.92rem;">
    Driven by a CLI and MCP, so your agent can set it up too — not just query it.
  </p>
</section>
